# Indhar P Portfolio 2.0

Welcome to **Indhar P Portfolio 2.0**, a modern and interactive portfolio showcasing the skills, projects, and experience of **Indhar Jain**, a Front-End Architect & Micro-Frontend Specialist.

## 🚀 Features

- **Dynamic 3D Background**: Powered by Three.js for an engaging visual experience.
- **Interactive Skills Visualization**: D3.js brings skills to life with draggable nodes.
- **Smooth Animations**: Framer Motion ensures a seamless user experience.
- **Responsive Design**: Tailwind CSS makes the portfolio look great on all devices.
- **Real-Time Updates**: Built with Vite for fast development and live reloading.

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript
- **Styling**: Tailwind CSS
- **3D Graphics**: Three.js
- **Data Visualization**: D3.js
- **Animations**: Framer Motion
- **Build Tool**: Vite

## 🚀 Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
